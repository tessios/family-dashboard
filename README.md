# 🏠 우리 가족 기록장

**🌐 배포 주소: https://tessios.github.io/family-dashboard/**

아빠 · 엄마 · 서진이(중2 · 뽑시) · 리아(7살 · 먹짱이) 네 사람이 함께 쓰는 모바일 웹앱입니다.
빌드 도구 없이 **순수 HTML/CSS/JS**만으로 만들어져서, 폴더째 올리면 바로 열립니다.

- 앱: `index.html` (한 파일에 화면·기능 전부)
- 이미지: `assets/` (가족 캐릭터 4종 + 앱 아이콘, 모두 이 프로젝트용 오리지널 생성 이미지)
- 설정: `manifest.json` (홈 화면에 추가할 때 쓰는 앱 정보)

## 쓰는 법

1. 폰 브라우저에서 주소를 연다.
2. **아이폰 Safari**: 공유 → 홈 화면에 추가 / **안드로이드 Chrome**: 메뉴 → 앱 설치.
3. 오른쪽 위 `기기 저장` 배지를 누르면 가족 동기화를 설정할 수 있다.
4. 설정 → 기록 백업에서 JSON을 내려받아 두면 기기를 바꿔도 복원된다.

### 새 기능 쓰는 법

- **내 상태**: 홈 맨 위 카드에서 지금 접속한 사람의 상태를 한 번에 바꾼다(아빠 🚗출근·🔧현장·🚇귀가 중·🛋휴식 / 엄마 💼미팅·🛍외출·🏠집·☕휴식 / 뽑시 📚공부 중·🏫학교/학원·🎮자유시간·😴휴식 / 먹짱이 🎨유치원/놀이·🍓간식시간·📖책 읽기·🌙낮잠/휴식). 바로 아래 `가족 지금`에서 네 사람 상태를 한눈에 보고, 누르면 그 사람 화면으로 바꾼다.
- **장보기**: 하단 `살림` 탭 → 물건을 적고 `담기`. 사 오면 동그라미를 눌러 체크, `산 것 지우기`로 정리.
- **저녁 메뉴**: `살림` 탭에서 메뉴를 눌러 한 표(다시 누르면 취소), `추가`로 새 메뉴를 넣는다. 1순위에 🏆가 붙고, 날짜가 바뀌면 투표는 자동으로 새로 시작한다.
- **당번 돌림판**: `살림` 탭에서 당번(분리수거·설거지·심부름·간식 쏘기·청소기)을 고르고 `돌리기`. 최근 8번 기록에서 덜 뽑힌 사람이 우선이라 공평하게 돌아가고, 결과는 `최근 기록`에 남는다.
- **보상 상점**: 용돈(서진이)·칭찬 별(리아)로 쿠폰을 교환한다. 모자라면 `교환` 버튼이 꺼지고, 교환 내역은 `교환 기록`에 남는다.
- **밤 모드**: 헤더 오른쪽 🌙/☀️ 버튼 또는 설정 → 🌙 밤 모드 스위치.

### 2026-11-18 추가: `기록` 탭 (펫 · 독서 · 키·몸무게 · 주간 리포트)

하단 `📔 기록` 탭에서 네 가지를 봐요. 위쪽 네 버튼으로 화면을 바꿉니다.

- **🐾 우리 집 펫**: 가족 모두가 함께 키우는 펫이에요. `밥 주기`·`놀아주기`·`씻기기`를 하면 포만감·기분·청결이 올라가고 경험치가 쌓여요(각 5분에 한 번). 경험치 20/60/140/260에서 알 → 아기 → 어린이 → 청소년 → 어른으로 자라고, 다 자라면 👑가 붙어요. 돌보지 않으면 포만감은 약 15시간, 기분은 20시간, 청결은 30시간에 걸쳐 0%까지 줄어요.
  - 펫 이름과 종류(강아지·고양이·햄스터·토끼·공룡)를 정할 수 있어요. 홈에도 미니 카드로 보여요.
  - 할 일을 끝내면 +2, 가족 미션은 +6, 공부 타이머를 마치면 +3, 책을 기록하면 +4 경험치가 함께 쌓여요. 아이들이 자기 일을 하면서 펫도 키우는 구조예요.
- **📚 독서기록**: `＋ 책 추가`로 제목·지은이·읽은 사람·읽은 날짜·별점(1~5)·한줄평을 남겨요. 사람별 필터, 이번 달 권수·가족 평균 별점·이번 주 권수를 보여줘요.
- **📏 키·몸무게**: `＋ 기록 추가`로 잰 날짜와 키(cm)·몸무게(kg)를 적어요. 둘 중 하나만 적어도 되고, 같은 사람·같은 날짜로 다시 저장하면 고쳐져요. 최근 값과 이전 기록 대비 증감(▲/▼), 최근 12개 변화 그래프를 보여줘요.
- **📊 주간 리포트**: 이번 주(월~일)의 할 일 완료 수, 도장(미션·할 일), 가족 공부 시간, 읽은 책, 펫 돌봄 횟수를 요일별 막대와 함께 보여줘요. `‹ 이전 주`로 지난주들을 볼 수 있고, 이번 주는 **지난주 같은 기간**(예: 월~수)과 비교해 줘요.

> 기록은 기존과 똑같이 `localStorage`와 가족 동기화(Supabase `family_state.data` JSON)에 함께 저장돼요. **새 테이블·컬럼 마이그레이션이 필요 없습니다.** 이전 버전 기록을 쓰던 기기·서버도 열면 펫·독서·성장 칸이 자동으로 만들어져요.

## 가족과 함께 쓰기 (Supabase, 선택)

한 기기에서만 쓰면 아무 설정도 필요 없습니다. 가족 폰·태블릿이 같은 기록을 함께 쓰려면:

1. [supabase.com](https://supabase.com) 무료 프로젝트 생성 (리전은 서울 `ap-northeast-2` 권장)
2. **SQL Editor**에서 아래 실행

```sql
create table if not exists public.family_state (
  id text primary key,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.family_state enable row level security;
create policy "family read" on public.family_state for select using (true);
create policy "family insert" on public.family_state for insert with check (true);
create policy "family update" on public.family_state for update using (true);
```

3. **Project Settings → API**의 Project URL과 anon public key를 앱의 동기화 설정에 붙여넣기
4. 20초마다 다른 기기의 기록을 확인하고, 변경이 있으면 자동으로 올립니다.

> ⚠️ 위 정책은 주소와 anon key를 아는 사람이 읽고 쓸 수 있는 가족용 설정입니다.
> 민감한 정보(전화번호·주소·비밀번호·계좌)는 절대 넣지 마세요.
> anon key는 원래 공개되는 키지만, 이 저장소 파일에는 **어떤 키도 넣지 않았습니다** (브라우저에만 저장).

## 💌 가족 초대 링크로 한 번에 연결

한 기기에서 Supabase를 연결했다면, 나머지 가족 폰은 **키를 입력할 필요가 없습니다.**

1. 연결된 기기의 **설정 → ☁️ 가족과 함께 쓰기 → 동기화 설정**을 연다.
2. 맨 아래 **💌 가족 초대 링크**의 `🔗 링크 복사` 또는 `📤 공유하기`를 누른다.
3. 그 링크(`https://tessios.github.io/family-dashboard/#sync=...`)를 가족에게 문자·카톡으로 보낸다.
4. 가족이 링크를 **한 번 열기만** 하면 주소·키가 자동으로 채워지고 같은 가족 기록에 연결된다.
   (연결되면 주소창의 `#sync=...`는 자동으로 지워지고, 그 폰에는 키가 그 폰의 브라우저에만 저장된다.)

- 이미 다른 기록에 연결된 기기에서 초대 링크를 열면, 바꿀지 먼저 물어본다. 기록은 설정 → 기록 백업으로 미리 내려받아 둘 수 있다.
- `#sync=` 값은 `{u: Project URL, k: 공개 키}`를 base64url로 담은 것이라, 코드나 저장소에는 키가 남지 않는다.
- 링크를 아는 사람은 그 가족 기록을 읽고 쓸 수 있으니 **우리 가족에게만** 보낸다.

## 개인정보

- 전화번호·집 주소·학교·계정 정보는 코드에 없습니다.
- 검색엔진 노출을 막기 위해 `noindex,nofollow`를 넣었습니다.
- 날씨는 송도 좌표(37.3923, 126.6344)로 Open-Meteo에 요청합니다. 개인 식별 정보는 보내지 않습니다.
- 공개 주소를 아는 사람은 페이지를 열 수 있으니, 가족만의 민감한 메모는 쓰지 마세요.
